## 文件放在哪

文章是 Markdown，放在 `public/blogs/` 下。第一级子目录就是分类，文件名会成为页面地址。

```
public/blogs/
├── tech/博客写作格式.md      → /blogs/tech/博客写作格式.html
├── design/网页排版原则.md
└── life/idea/远程办公心得.md  → 二级目录同样生效
```

不要手写 HTML。构建时脚本会套用 `model/blog_model.html`。

## Front matter

文件开头需要有一段 `---` 包裹的元数据，字段名后用英文冒号，标签用英文逗号分隔：

```md
---
title: 博客写作格式
tags: 教程, 工具
date: 2025-07-18
desc: 一句话摘要，会出现在文章列表卡片上。
---
```

| 字段 | 作用 |
|------|------|
| title | 页面标题。缺省时用文件名 |
| tags | 标签页链接，多个标签用逗号分隔 |
| date | `YYYY-MM-DD`，列表按它倒序 |
| desc | 列表卡片摘要 |

## 正文

正文标题从二级、三级标题开始。页面大标题来自 `title`，正文里不必再写一级标题。

### 可以使用的元素

- 有序、无序列表
- 带语言标记的代码块
- 引用、表格、链接

> 改完 Markdown 后执行生产构建，列表、分类和标签页会一起更新。
